# Repository workflow

- Keep changes focused and preserve the extension's dependency-free runtime.
- Run the relevant regression tests, browser checks, and package validation before merging.
- The maintainer's standing instruction is to merge completed, validated work into `main`. Do not stop at an open pull request unless they explicitly ask for review only or an unresolved issue prevents a safe merge.
- Delete the completed work branch after merging. Preserve branches that contain unfinished work.
- Browser-store publication is a separate step from merging to GitHub.
