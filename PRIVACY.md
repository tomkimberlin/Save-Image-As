# Privacy Policy for Save Image As

Effective date: August 18, 2026

Save Image As converts images selected by the user into PNG, JPG, or WebP files. The extension is designed to perform that work locally in the browser.

## Data Collection

Save Image As does not collect, sell, share, or transmit personal information, browsing history, image contents, analytics, or usage data to the developer or any developer-operated service. The extension has no accounts, advertising, tracking, telemetry, or external backend.

## Image Processing

When the user explicitly selects a **Save image as** command, the extension accesses that selected image and processes it in browser memory. The converted result is written only to the download location chosen by the user. Some images must be requested from the website or image host that already serves them; these requests go to the image's existing source, not to the developer.

## Settings

The extension stores JPG quality, WebP quality, and Save As dialog preferences using the browser's synchronized extension-storage feature. Depending on the user's browser and account settings, the browser vendor may synchronize those preferences between the user's devices. The developer cannot access them.

## Permissions

- **Context menus:** Adds the user-invoked image conversion menu.
- **Downloads:** Saves the converted file to the user's device.
- **Storage:** Remembers the user's conversion preferences.
- **Scripting:** Accesses the selected image in its page only when direct conversion is unavailable.
- **Website access:** Allows the extension to process a user-selected image regardless of which website or image host serves it.

## Open Source

Save Image As is open-source software and is committed to remaining open source. Its code and change history are publicly available at <https://github.com/tomkimberlin/Save-Image-As>.

## Changes to This Policy

Material changes to this policy will be published in the repository and reflected in the extension's store listings. The effective date above will be updated when the policy changes.
