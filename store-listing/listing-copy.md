# Store Listing Copy

This copy is intended for Chrome Web Store, Microsoft Edge Add-ons, and Firefox Add-ons. Keep the extension name and summary consistent across stores.

## Name

Save Image As

## Short Description

Right-click images to convert and save them as PNG, JPG, or WebP—locally, privately, and open source.

## Detailed Description

Convert and download web images in the format you actually need. Save Image As adds a simple right-click menu that lets you export an image as PNG, JPG, or WebP without opening a separate editor or uploading the image to an online converter.

Choose PNG for lossless quality and transparency, JPG for broadly compatible photo files, or WebP for efficient modern compression. Adjustable JPG and WebP quality controls let you balance image quality and file size, and an optional Save As dialog gives you control over the destination and filename.

Save Image As processes images locally in your browser. It has no accounts, ads, analytics, tracking, or developer-operated servers.

The extension is open source and will remain open source. Anyone can inspect its code and complete change history at https://github.com/tomkimberlin/Save-Image-As.

Features:

- Convert images from the browser's right-click menu
- Save as PNG, JPG, or WebP
- Preserve transparency in PNG and WebP when supported
- Fill transparent areas with white when exporting to JPG
- Adjust JPG and WebP output quality
- Choose whether the browser displays a Save As dialog
- Process images locally without uploading them to a conversion service
- Review the complete source code and development history publicly

Some websites restrict access to their images in ways that can prevent browser extensions from converting them. Animated images are exported as a single frame.
